# Client Learning Notes

This client folder is part of a first learning session. It contains example Vue 3 and Vite code that can be used to understand the current UI structure before making larger changes.

## What This Folder Is Right Now

- A sandbox for learning the Vue client structure.
- A reference implementation for the planning poker screens and socket flow.
- Not a final product or polished starter.
